# 月亮邮局 · 一封月光信

中秋（农历八月十五）互动单页。月宫有个邮局，玉兔值夜班——写一封信，它替你送到。

- 单文件 HTML，无框架、无构建、无 CDN，核心完全离线可用
- 信件只保存在访问者自己的设备上（localStorage），**绝不上传任何服务器**
- 玉兔、邮局、邮票全部纯 CSS + 内联 SVG 绘制，无图片素材
- Web Audio 程序化音效（捣药杵、信纸、风声、盖戳、信变光），无音频文件
- 移动端优先，微信内置浏览器可顺畅使用；支持系统「减弱动态效果」

## 三种寄法

| 收件人 | 处理 |
| --- | --- |
| 还在身边的人 | 走人间线，玉兔替你送到 |
| 放在月亮上 | 月亮是你们共用的地址 |
| 写给未来的自己 | 密封 + 选送达日，到那天玉兔会提醒你 |

## 流程

序章 → 写信台 → 投递 → 月宫分拣 → 捣药（信捣成光）→ 盖月戳 → 送达 → 月宫运单 → 尾声（换班留言 + 邮戳墙）


或者直接双击 `index.html`。

## 设计红线

不做输赢、不做排行榜、不做任何形式的打分；玉兔只做送信的——不评价、不诊断、不给建议，共情只在「值夜班」这一层。
